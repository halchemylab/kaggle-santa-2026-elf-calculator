Goal: minimize total arithmetic instructions over scored_0001 through scored_1000.
Each puzzle has starting_values, targets, value_limit, and 48 registers. An
instruction is [op, source_a, source_b, destination] for +, -, *, or exact /.
Both operands are read before destination overwrite; sources may be identical.
Only defined registers can be read. Every value must be a positive integer <= the
puzzle's limit. Use Python integers. Programs must cover every target at least
once, use <=4096 instructions, and occupy <=131072 UTF-8 bytes per program cell.
Every instruction counts; every instruction must be legal even after coverage.
One invalid puzzle rejects the submission. CSV columns must be exactly id,program,
with all 1000 scored IDs once each and JSON instructions escaped by csv.writer.
